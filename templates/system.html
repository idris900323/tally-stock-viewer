Duplicate images

Finds image rows that look like duplicates (same folder, same base filename) and confirms with a content hash so two different photos that merely share a generic filename aren't flagged. This is list-only — nothing is deleted.

Badge cache

Lists every file in the real share_cache/ folder on this machine (filename, size, real modified time) so a stale cached badge can be confirmed by mtime instead of guesswork. Badged files (*_badge_*.jpg) carry the badge-drawing code's own version number in their filename (see BADGE_FORMAT_VERSION in app.py) -- any future change to how badges are drawn bumps that constant, which makes every existing badge file miss its cache key and regenerate fresh automatically, with no manual clearing needed. "Clear Badge Cache" below is the on-demand manual option for right now.
